
# Recipe Website

This project will be a basic recipe website that will demonstrate my current progression from learning HTML through 'The Odin Project'.

## Reflection

This project took me about 1 hour and 30 minutes to complete. It taught me a lot of the HTML fundamentals and how most webpages are formatted, and how to navigate between the different pages within the file structure. I also learned how to add captions to any photos I included in my recipe pages, along with how I should credit the authors of the original photo.
